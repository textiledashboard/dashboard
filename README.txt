REVAMP TEXTILE DASHBOARD - STATIC VERSION

FINAL LOCKED COLOUR PALETTE: Original navy, teal and lime theme.

PRODUCTION MODULE
- Full-page fibre filter: All Fibres, Cotton, Silk, Jute, Wool, MMF and Handloom
- Fibre-specific KPI cards at the top
- Fibre-specific chart types, units, periods, sources and state comparisons
- Fibre-specific insight cards at the bottom
- Chart-only PNG export
- Numbered Y-axis references and interactive hover tooltips
- Illustrative dummy data ready for later replacement

OTHER MODULES
- Production remains fully accessible.
- Every unfinished module displays a polished "being crafted" screen.

DATA UPLOAD MODULE
- Open Upload Data from the sidebar or top-right button.
- Supports JSON, CSV, Excel, PDF and DOCX files.
- Preview rows and map columns to Production charts, KPI cards or insights.
- Imported data is saved in the current browser using local storage.
- Download JSON Backup to preserve or publish the updated dataset.
- For permanent GitHub Pages updates, commit the downloaded JSON/data build.
- Excel/PDF/DOCX parsing libraries require an internet connection when opening
  this static version. JSON and CSV imports work without those libraries.

HOW TO RUN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html.

No Node.js, npm, server or installation is required.

GITHUB PAGES
Upload index.html and the css and js folders to a GitHub repository, then enable GitHub Pages.
